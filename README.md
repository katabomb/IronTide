# IRON TIDE｜八幡浜機関戦線

**港に、鉄の潮が来る。**

夜の八幡浜の造船所を舞台に、からくり兵器で異星群体を迎え撃つ、ブラウザで遊べる一人用リアルタイムストラテジーゲームです。

採掘機で鉱石を集め、歩行機やリンク砲を生産。基地の防衛と敵拠点への進軍を同時に指揮します。

※八幡浜をモチーフにした架空のSF作品です。地形や施設はゲーム用に構成しています。

## 特徴

- **HTMLファイル1個で動作**：ダウンロードしてブラウザで開くだけ。インストールやビルドは不要です。
- **オフラインで遊べる**：外部ライブラリ・画像・音声ファイルを使用していません。
- **資源管理と部隊指揮**：自動採掘、生産、防衛、進軍を組み合わせて戦います。
- **機械兵器と異星群体**：暗い港湾を舞台にした、シンプルな図形による戦場表現。
- **3段階の難度**：偵察・迎撃・包囲から選べます。
- **一時停止に対応**：戦況を確認してから操作を再開できます。
- **効果音を切り替え可能**：ブラウザ内で合成した効果音を使用します。初期設定はOFFです。

## 遊び方

1. `IRON_TIDE.html` をダウンロードし、ブラウザで開きます。GitHub Pagesに公開する場合は、同じファイルを `index.html` に変更してください。
2. 作戦難度を選び、「作戦開始」を押します。
3. 採掘機を増やして鉱石収入を確保し、戦闘部隊やタレットを生産します。
4. 基地を守りながら、画面右上の異星巣核へ部隊を進めます。

**異星巣核を破壊すると勝利、味方の司令部が破壊されると敗北です。**

初期配備は、採掘機2機・螺旋歩行機2機・四節リンク砲1機。初期鉱石は240です。採掘機と防衛タレットを含め、保有できる機体は最大30です。

## 操作方法

| 操作 | 内容 |
| --- | --- |
| 味方の移動戦闘機体をクリック | その機体を選択 |
| 戦場をドラッグ | 範囲内の移動戦闘機体をまとめて選択 |
| Shift＋味方をクリック | 選択中の部隊に機体を追加 |
| 部隊を選んで地面をクリック／右クリック | 指定地点へ移動 |
| 部隊を選んで敵をクリック | 指定した敵を攻撃 |
| A／「全戦闘部隊を選択」 | 全ての移動戦闘機体を選択 |
| F／「敵拠点へ進軍」 | 全ての移動戦闘機体に巣核への攻撃を指示 |
| D／「基地へ撤退」 | 全ての移動戦闘機体に基地前方への移動を指示 |
| Space／「一時停止」 | 一時停止・再開 |
| 「音：OFF／ON」 | 効果音の切り替え |

スマートフォンでは、味方をタップして選び、目的地や敵をタップして指示します。まとめて動かす場合は「全戦闘部隊を選択」を利用してください。細かな部隊操作には、マウスを使えるPCが向いています。

採掘機は自動で鉱床へ移動して採掘します。手動での移動指示は不要です。タレットの設置位置は自動で決まります。

一時停止中は移動指示・生産・修復を行えません。別のタブなどへ切り替えると自動で一時停止します。

## 機体・設備

| 名称 | 必要鉱石 | 役割 |
| --- | ---: | --- |
| 採掘機 | 60 | 近くの鉱床で自動採掘。資源収入を増やす |
| 螺旋歩行機 | 80 | 足の速い移動戦闘機体。近距離で敵を迎撃する |
| 四節リンク砲 | 150 | 移動は遅いが、長射程・高耐久の砲撃機体 |
| 防衛タレット | 120 | 基地前方に設置される固定砲。長射程で防衛を支援する |
| 基地修復 | 100 | 司令部の耐久力を180回復する |

敵を撃破しても鉱石を獲得できます。敵の襲撃は繰り返し発生し、波が進むと数が増え、重装の敵も現れます。

## 難度

| 難度 | 内容 |
| --- | --- |
| 偵察（やさしい） | 襲撃の間隔が長く、部隊を整える時間を確保しやすい |
| 迎撃（標準） | 基本となる難度 |
| 包囲（難しい） | 襲撃の間隔が短く、巣核からの増援も頻繁になる |

最初の大規模襲撃は、どの難度でも開始から約35秒後です。

## 攻略のヒント

- 序盤は採掘機を増やし、継続的に生産できる状態を作ります。
- 防衛タレットで基地を守り、移動部隊を攻撃に回します。
- 足の速い歩行機と長射程のリンク砲を組み合わせます。
- 巣核へ進軍中も基地の様子を確認し、必要に応じて撤退や修復を行います。

## GitHub Pagesで公開する

1. ゲーム本体の `IRON_TIDE.html` を **`index.html`** に変更します。
2. リポジトリの最上位に `index.html` と、この `README.md` をアップロードします。
3. リポジトリの **Settings → Pages** を開きます。
4. **Build and deployment** の **Source** で **Deploy from a branch** を選びます。
5. **Branch** を `main`、フォルダーを `/(root)` に設定し、**Save** を押します。
6. 公開が完了したら、Pagesの設定画面に表示されるURLから遊べます。

ブランチ名が `main` 以外の場合は、ゲーム本体を置いたブランチを指定してください。

参考：[GitHub Pagesの公開元を設定する（GitHub公式ドキュメント）](https://docs.github.com/ja/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## ファイル構成

## 技術構成

| 技術 | 用途 |
| --- | --- |
| HTML / CSS | 画面構成・レスポンシブレイアウト |
| JavaScript | 資源管理・生産・部隊移動・戦闘・敵の襲撃 |
| Canvas 2D API | 戦場・機体・砲撃・エフェクトの描画 |

サーバー・データベース・APIキー・パッケージのインストールは不要です。

## 現在の仕様

- 一人用、1マップのゲームです。
- 対戦通信・セーブ・途中再開機能はありません。ページを再読み込みすると初期画面に戻ります。
- 戦闘機体は射程内の敵を自動攻撃します。移動指示中でも交戦することがあります。
- 建物や背景は演出で、障害物を迂回する経路探索は実装していません。
- スマートフォンでは画面サイズにより戦場や操作ボタンが小さく表示されます。
